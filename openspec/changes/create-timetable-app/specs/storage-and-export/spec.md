## Purpose

時間割データ、講義情報、課題、出欠記録をブラウザのローカルストレージに自動保存・復元し、JSONファイルによるバックアップ/復元や、ICS（カレンダー連携）・画像形式でのエクスポート機能を提供します。

## ADDED Requirements

### Requirement: ブラウザローカルへの自動保存と読み込み
システムは、時間割、講義、課題、出欠のすべての変更をブラウザのLocalStorageに即座に自動保存し、再読み込み時にも状態を復元しなければならない（SHALL）。

#### Scenario: ページ再読み込み時のデータ復元
- **WHEN** ユーザーがデータを更新した後にブラウザをリロードした時
- **THEN** システムはLocalStorageからデータを読み込み、前回の状態を完全に復元して表示する

### Requirement: JSON形式でのデータエクスポートおよびインポート
システムは、登録されている全時間割データをJSONファイルとしてダウンロード（エクスポート）し、また外部のJSONファイルを読み込んで復元（インポート）できなければならない（SHALL）。

#### Scenario: JSONバックアップファイルのダウンロード
- **WHEN** ユーザーが設定画面で「データをJSONでエクスポート」をクリックした時
- **THEN** システムは全時間割および課題・出欠データを含むJSONファイルを生成してブラウザからダウンロードさせる

#### Scenario: JSONファイルからの復元
- **WHEN** ユーザーがバックアップJSONファイルを選択してインポートを実行した時
- **THEN** システムはJSONのスキーマを検証した上で既存データを上書き（またはマージ）し、画面を更新する

### Requirement: iCalendar (ICS) 形式でのカレンダーエクスポート
システムは、登録された時間割スケジュール（曜日、開始・終了時刻、講義名、教室等）をiCalendar形式（.ics）でエクスポートできなければならない（SHALL）。

#### Scenario: ICSファイルのダウンロード
- **WHEN** ユーザーが「カレンダー形式（.ics）でエクスポート」を実行した時
- **THEN** システムは学期の開始日・終了日に基づいて定期的なカレンダーイベントを生成し、.icsファイルとしてダウンロードさせる

### Requirement: 時間割画像の出力と印刷対応
システムは、時間割グリッドを画像（PNG）として保存するか、印刷に最適化されたレイアウトで印刷ダイアログを開くことができなければならない（SHALL）。

#### Scenario: 時間割画像（PNG）の保存
- **WHEN** ユーザーが「画像として保存」をクリックした時
- **THEN** システムは時間割グリッドを画像としてレンダリングし、PNG画像ファイルをダウンロードさせる
