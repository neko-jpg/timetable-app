## Purpose

講義に紐づく課題・提出物・ToDoの進捗と締切を管理し、講義ごとの出欠カウント（出席/欠席/遅刻/休講）および単位取得に向けた警告通知機能を提供します。

## ADDED Requirements

### Requirement: 講義別課題の登録と期限管理
システムは、各講義に紐づく課題（タイトル、締切日時、種別［レポート/小テスト/発表/その他］、詳細メモ）を登録・編集・削除できなければならない（SHALL）。

#### Scenario: 課題の新規登録
- **WHEN** ユーザーが特定の講義の詳細または課題管理画面から課題名と提出期限を入力して追加した時
- **THEN** システムはその講義に関連付けられた新しい課題として保存し、一覧に表示する

#### Scenario: 課題の完了状態の切り替え
- **WHEN** ユーザーが課題のチェックボックスをクリックした時
- **THEN** システムは課題のステータスを「未完了」から「完了」（またはその逆）に切り替え、完了日を記録する

### Requirement: 直近の課題リマインダー・ダッシュボード表示
システムは、未完了の課題を締切が近い順に並べたダッシュボードまたはサマリーリストを表示しなければならない（SHALL）。

#### Scenario: 締切直前の課題ハイライト
- **WHEN** 締め切りまで24時間以内の未完了課題が存在する時
- **THEN** システムはダッシュボード上でその課題を警告色（赤色またはバッジ）で強調表示する

### Requirement: 講義ごとの出欠カウント管理
システムは、講義ごとに「出席」「欠席」「遅刻」「休講」「補講」の回数を手動でカウント・記録できなければならない（SHALL）。

#### Scenario: 出欠カウントの増減
- **WHEN** ユーザーが講義カード上の「欠席」ボタン（＋）をクリックした時
- **THEN** システムは該当講義の欠席回数を1増やし、最新のカウント数を表示する

### Requirement: 欠席上限と単位取得アラート
システムは、講義ごとの総授業回数または規定の欠席許容上限（例: 全15回中4回欠席で単位落下の危険）に基づき、欠席が規定値に達した際に警告アラートを表示しなければならない（SHALL）。

#### Scenario: 欠席上限接近時の警告
- **WHEN** 講義の欠席回数が規定の注意ライン（例: 3回以上）に達した時
- **THEN** システムは該当講義に「欠席注意」の警告バッジを表示し、ユーザーに注意を促す
