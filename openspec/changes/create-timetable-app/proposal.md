## Why

学生や受講生が自身の受講講義や授業スケジュール、課題、出欠状況を一元的に管理できる、直感的でモダンなWebベースの「時間割アプリ」を新規開発します。
既存のカレンダーアプリでは管理しづらい「曜日×時限」のグリッド形式、課題の締切管理、出欠カウントなどをスムーズに行える環境を提供し、学業生活のスケジュール管理を効率化します。

## What Changes

新規のWebアプリケーション（時間割アプリ）を構築します。
- **時間割グリッド表示と講義管理**: 曜日（月〜金/土日対応）× 時限（1〜7限など柔軟に設定可能）のグリッドビュー、講義の登録・編集・削除（講義名、教室、教員、単位数、テーマカラー、メモ等）。
- **複数時間割（学期別）管理**: 前期/後期や年度ごとの時間割切り替え。
- **課題・ToDo管理**: 講義に紐づく課題や提出物の期限管理、完了チェック、ダッシュボードでの期日アラート。
- **出欠管理機能**: 出席・欠席・遅刻・休講・補講の記録および単位取得に向けた警告表示。
- **データ永続化と共有・エクスポート**: LocalStorage を利用したオフライン動作とブラウザ内保存、JSONバックアップ/復元、ICS（カレンダー連携）や画像・印刷用エクスポート。
- **レスポンシブ＆モダンUI**: スマートフォン・タブレット・PCに最適化されたUI、ダークモード/ライトモード対応。

## Capabilities

### New Capabilities
- `timetable-management`: 曜日×時限グリッド表示、講義情報（講義名・教室・教員・カラー等）の登録・編集・削除、時限・曜日カスタム設定、学期切り替え機能。
- `assignment-attendance`: 講義に紐づく課題・タスクの期日管理および出欠状況（出席/欠席/遅刻/休講）のカウント・管理機能。
- `storage-and-export`: ブラウザLocalStorageへのデータ自動保存・復元、JSON形式によるインポート/エクスポート、画像/カレンダー形式での共有機能。

### Modified Capabilities
- なし

## Impact

- **新規プロジェクト構成**: React / TypeScript / Vite / Tailwind CSS / Lucide React などのモダンなフロントエンドスタックによるSPA構成。
- **ブラウザ内完結**: サーバーレスで動作し、LocalStorage による完全ローカル管理でプライバシーを保護。
